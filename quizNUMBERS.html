How QuizTally Mode works
Example quizQuestion 1 of 30
  1. Tap Rename and give each score a person's name, one per person taking the quiz.
  2. Each answer in the video is worth points. When someone picks an answer, tap that many points for them. A red purse might be +2, while the blue purse would have been +4.
  3. At the end, check each person's total against the video's result chart to find their personality type. There is no winner, so you can turn the crown off with its switch.

AI Cards
The games already make new cards without any setup. This is an extra, if you want an AI to write them.
Works without an API. Truth or Dare, Who's Most Likely To, Never Have I Ever, Would You Rather and Charades mix hand-written cards with ones the app builds from word banks, so they rarely repeat. Everything is kid-safe and works offline.
How to add an API key
  1. Go to console.anthropic.com and sign in or create an account.
  2. Add a small amount of credit and set a low monthly spend limit in the Console's billing settings.
  3. Open API Keys, create a key, and copy it.
  4. Paste it above, leave the model as it is, press Save, then Test.
Kid-safe by design. Every request tells the AI the players are ages 8 to 12 and asks for clean, silly, friendly cards only. The app also checks each card against a blocklist before showing it, throws out anything that fails, and falls back to the offline cards if the AI is slow, offline, or returns something unusable. The kid-safe rules cannot be switched off here.
About your key. It is saved only in this browser on this device and is sent only to api.anthropic.com. Anyone who can use this browser can find it, so use a key with a low spend limit, and do not publish this page with a key inside it. If you share the game widely, run the AI call from a small server of your own instead.
